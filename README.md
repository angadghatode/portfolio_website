# 🕹️ ANGAD_v2.0 | Portfolio

A retro-inspired, high-performance pixel art portfolio built with **React** and **Vite**. This system uses a multi-layered parallax architecture and an 8-bit aesthetic to showcase my active quests and tech arsenal.

## 🌌 System Overview

This interface is designed to emulate a vintage gaming console while maintaining modern web standards.

* **Parallax Architecture**: 5-layer horizontal and vertical parallax depth effect.
* **Dynamic UI**: Powered by **NES.css** for that authentic 16-bit look and feel.
* **Responsive Engine**: Designed to scale across different viewport resolutions.

## 🛠️ Tech Arsenal

* **Core**: React 19
* **Styling**: CSS3 (Custom Keyframes & Intersection Observer API)
* **UI Framework**: NES.css
* **Build Tool**: Vite (Rolldown)
* **Deployment**: GitHub Pages

## 🚀 Installation & Deployment

To run this system locally:

1.  **Clone the repository**
    ```bash
    git clone [https://github.com/your-username/my-pixel-portfolio.git](https://github.com/your-username/my-pixel-portfolio.git)
    ```

2.  **Install dependencies**
    ```bash
    npm install
    ```

3.  **Launch the development server**
    ```bash
    npm run dev
    ```

4.  **Configure the contact form**

    Get an access key from [Web3Forms](https://web3forms.com/), then set
    `VITE_WEB3FORMS_ACCESS_KEY` in a local `.env` file (see `.env.example`).
    Add the same variable to the Vercel project's Environment Variables for
    each deployment environment, then redeploy. Vite embeds `VITE_` variables
    in the client bundle; Web3Forms access keys are designed to be public.

5.  **Deploy to GitHub Pages**
    ```bash
    npm run deploy
    ```

## 🎮 Features

* **Mission Cards**: Interactive project displays with hover-glow effects and status indicators.
* **Command Terminal**: A functional "Uplink" contact form styled as a secure communication terminal.
* **Parallax Banner**: A synchronized horizontal scroll featuring a night-city skyline and a physics-based "car rumble" animation.
